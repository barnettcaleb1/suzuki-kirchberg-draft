# Scope of conditional Lean verification

The exact target is `Suzuki.Target.MainClaim.{u}`: every actual unital complex C*-algebra B satisfying `Target.IsKirchberg` has `Target.HasFiniteAmalgam`. The conclusion exhibits actual common and factor algebras in the same carrier universe u, all separable, nuclear, nonzero simple and stably finite, injective common inclusions, and the full universal amalgam property on B itself. It is not a reduced product or a statement only about matching K-groups.

`fullTheoremConditional` has only category/typeclass parameters and `P : PublishedInputs`; it proves that exact proposition. The full compiled nested input signatures are in `conditional-hypotheses.txt`. The final theorem source, all imports, audits and review targets are hash-bound. Review applies to those bytes only.

Norms are genuine complex C*-norms. Positivity is spectral positivity. Nuclearity is finite-set/epsilon approximation by completely positive contractive maps through positive-size full complex matrix algebras. Simplicity concerns all norm-closed two-sided ideals and excludes zero. Pure infiniteness means each nonzero positive element's norm-closed hereditary subalgebra contains an infinite projection. Stable finiteness is absence of proper matrix isometries at every finite size. The ordinary-standard equivalence of these exact conventions is part of the published-interface interpretation.

The graph convention is A(v,w) edges w→v, so the conventional transposed source-row adjacency minus identity is B=A−I. Finite-cone K0 uses left minus right factor classes and K1 boundary (−y,y). The initial two vertex classes are +1 and −1, derived from ordinary rank normalization. Composition of classes is written left to right. Carrier universe u, KK object universe v, Hom universe w and graph K-group universe t are explicit. The intended category consists of designated separable KK objects, including nonunital coefficients, suspensions, tensor stages and completed limits. All-Z Milnor quantifiers are over those objects.

UCT is an explicit input only for the scalar finite-cone/graph/reference bootstrap sources. It is never assumed for the target B, the coefficient F, its unitization E, or the tensor stages. No Kunneth theorem for the coefficient appears.

The manuscript's new finite lifting, graph identification, orthogonal coefficient channels, KK bond calculation, actual limit arguments, common projection and unit equation are derived.
