3. COEFFICIENT CONE MODEL
The cone is the actual closed nonunital star subalgebra of C([0,1],H) x I defined by f(1)=0 and f(0)=theta(x), for a genuine complex nonunital star homomorphism theta. It does not presume I or H is unital. The subalgebra operations and its norm-closedness are proved explicitly; completeness and NonUnitalCStarAlgebra come from the closed-subalgebra instances.
Independent probes confirm the exact norm formula ||(f,x)|| = max(||f||_sup,||x||), the C*-identity, completeness, norm bounds for evaluation and projection, and both endpoint equations. For injective theta the isometry of theta yields ||(f,x)|| = ||f||_sup, so the cone has the intended inherited norm rather than an opaque or finite-dimensional replacement. The compact terminal-zero model is mathematically the usual C_0([0,1),H) model; its formal equivalence to whichever external mapping-cone interface is selected is still a later correspondence obligation.
Projection is genuinely surjective for arbitrary theta via the explicit path (1-t) theta(x). This is only a surjectivity witness, not a star-homomorphic splitting. A midpoint probe proves the corresponding scalar ramp of 1 is not idempotent, preventing an accidental multiplicative-section reading. Kernel-of-projection endpoint probes give vanishing at both endpoints, but the source does not claim a completed suspension/kernel equivalence or semisplit exact sequence.
Injectivity of theta is essential to separation by path evaluations: a nonzero ideal coordinate must produce a nonzero initial path value if all other path values vanish. The negative probe takes theta=0 on C and the genuine nonzero cone element (0,1). Every path evaluation is zero while its actual cone norm is 1. Thus dropping injectivity would make the claimed evaluation separation false.
RFD is proved by composing actual point evaluations with actual positive-dimensional finite matrix representations of H. External unitization is handled by the previously checked UnitizationRFD module; the scalar coordinate is separately detectable. The separable cone instance follows from second countability of continuous maps on the compact interval, products, and metric subspaces, under explicit separability of I and H. The tail conclusion means: for every N and every nonzero a, some n >= N has rho_n(a) != 0. Concrete identity-cone probes on C compile both actual unital RFD and separating-tail consequences.
No nuclearity, semisplit extension, Bott periodicity, cone KK equivalence, or full nuclear RFD coefficient-model conclusion is an input or theorem of this module. Those remain separately required. No source repair is required.
